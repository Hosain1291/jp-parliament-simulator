# jp-parliament-simulator
일본 중의원의원 선거에 대한 자신의 성향으로 만드는겁니다

**중의원 시뮬레이터 衆議院 · 1996 — 2026**

[국회 시뮬레이터](https://github.com/Hosain1291/national-assembly-simulator)와 같은 방식의 일본판입니다.
1996년 소선거구비례대표병립제 도입 이후 11번의 중의원 총선 가운데 하나를 고르고, 분야별 중요도를 정한 뒤
쟁점마다 막대를 움직여 답하면 당신의 입장대로 중의원이 다시 구성됩니다.

## 흐름
1. **총선 고르기** — 제41회(1996)부터 제51회(2026)까지. 정당 성향, 선거제도, 실제 의석
2. **분야별 중요도** — 정치·행정 / 헌법·안보 / 외교·역사 / 경제·재정 / 사회보장·노동 / 사회·인권 / 지역·에너지
3. **질문** — A안 ↔ B안 막대, 아래에 실시간 예상 의석
4. **분야별 의석 발표** — 분야마다 의석이 늘고 줄어드는 애니메이션
5. **결과**
   - 반원 부채꼴(arch) 의석 — 지역구는 채운 원, 비례는 고리
   - **내각총리대신 지명선거** — 반원 바로 아래. 1차 투표 → 과반 없으면 결선. 정당별 투표 방침을 바꿀 수 있음
   - 위키백과식 선거 인포박스
   - 도도부현 지도 (`jp.json`)
   - 분야별 의석, 정당 스펙트럼 맵, 의결 정족수(과반·안정다수·절대안정다수·3분의 2)
   - 연립 정권 구성과 내각 부처 배분
   - 나와 가까운 정당, 질문별 표결

테마: 자동 · 라이트 · 다크 · 핑크(#7B1C4F) · 올드 페이퍼 · 윈도우 95

## 파일 구성
```
index.html              화면 뼈대 (서버 없이 파일을 바로 열어도 동작)
css/style.css           스타일과 테마 6종
js/data-elections.js    총선·정당 데이터 (의석, 정당색, 대표, 총리 후보, 연립)
js/data-questions.js    총선별 쟁점 질문과 정당 위치
js/data-prefs.js        47개 도도부현 이름·정원·지역 성향
js/data-map.js          jp.json에서 만든 지도 경로 (자동 생성)
js/engine.js            계산 엔진 (의석 배분, 총리 지명, 연립, 지도 배치)
js/app.js               화면 5단계
tools/build_map.py      jp.json → js/data-map.js 변환
jp.json                 도도부현 경계 원본 (simplemaps)
favicon/favicon.svg     아이콘
CLAUDE.md               커넥터(Claude)로 고칠 때의 규칙
```

## 고치는 법
코드를 몰라도 `js/data-*.js`만 고치면 됩니다. GitHub 커넥터로 Claude에게 “2024년 공명당 색을 바꿔줘”, “2026년 질문을 하나 추가해줘”처럼 요청해도 됩니다. 규칙은 `CLAUDE.md`에 있습니다.

- 정당색 → `js/data-elections.js` 맨 위 `C`
- 총리 후보·연립 → 각 총선의 정당 항목 마지막 칸, `gov`, `pmBloc`
- 질문 추가·수정 → `js/data-questions.js`
- 지도 경계를 바꿨다면 → `python tools/build_map.py`

## 실행
`index.html`을 브라우저로 열면 됩니다. GitHub Pages(Settings → Pages → `main` / root)로 공개할 수도 있습니다.

## 출처와 한계
- 의석·득표: 위키백과 각 총선 문서. 2026년 총리 지명 결과(다카이치 354표), 2024년 결선(이시바 221 · 노다 160)
- 정당색: 위키백과 정당색 기준, 확인하지 못한 일부(중도개혁연합 등)는 근사값
- 질문과 정당 위치는 대표 쟁점을 단순화한 것이라 실제 당론과 다를 수 있습니다
- 비례대표는 11개 블록 동트식 대신 전국 단위로 계산합니다. 지도는 정당별 지역구 의석을 지역 성향으로 나눈 추정 배치입니다
