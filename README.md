# jp-parliament-simulator
일본 중의원의원 선거에 대한 자신의 성향으로 만드는겁니다

일본 중의원(衆議院) 총선거 465석(지역구 289 + 비례 176)을 득표율로 시뮬레이션하는 웹입니다.
반원 부채꼴 의석 차트 바로 아래에서 **내각총리대신 지명선거(首班指名)** 결과를 확인할 수 있습니다.

## 기능
- **득표율 설정** — 지역구/비례를 따로 조정, 시나리오(2026 총선 실제·여야 박빙·다당제 혼전)
- **반원 의석 차트(arch)** — 정당별 부채꼴, 과반선 233, 범례에 마우스를 올리면 해당 정당 강조
- **총리 지명선거 표** — 1차 투표에서 과반이 없으면 상위 2인 결선. 정당별 투표 방침(자당 후보/타당 후보/백지)을 바꿀 수 있음
- **정당별 의석표** — 지역구·비례·합계와 2026년 실제 결과 대비 증감
- **도도부현 지도** — `jp.json` 기반. 지역구 1위 정당 / 비례 블록 1위 정당 보기, 지역을 누르면 선거구별 결과와 지역 성향 보정 슬라이더
- **테마 6종** — 자동, 라이트, 다크, 핑크(#7B1C4F), 올드페이퍼, 윈도우 95

## 파일 구성
```
index.html            화면 뼈대
css/style.css         스타일 + 테마(data-skin)
js/sim.js             선거 계산 엔진 (지역구 다수제, 비례 동트식, 총리 지명 투표)
js/arch.js            반원 부채꼴 의석 차트
js/map.js             jp.json → SVG 도도부현 지도 (오키나와 인셋)
js/app.js             화면 조립, 상태 저장
data/parties.json     정당·색·총리 후보·기본 투표 방침·시나리오
data/prefectures.json 47개 도도부현 지역구 정원·비례 블록·지역 성향
data/blocks.json      비례 11개 블록 정원·블록 성향
jp.json               도도부현 경계 (simplemaps)
CLAUDE.md             커넥터(Claude)로 수정할 때의 규칙
```

## 실행
`fetch`로 JSON을 읽기 때문에 파일을 더블클릭(file://)하면 열리지 않습니다.
- **GitHub Pages**: Settings → Pages → Branch `main` / root 선택
- **로컬**: `python -m http.server` 후 `http://localhost:8000`

## 수정하는 법
코드를 몰라도 `data/` 폴더의 JSON만 고치면 됩니다.
- 정당 색 → `data/parties.json`의 `color`
- 총리 후보 → `pm_candidate`(일본어), `pm_candidate_ko`(한국어)
- 연립(예: 유신회가 자민당 후보에 투표) → `pm_vote`에 상대 정당 `id`
- 새 시나리오 → `presets`에 항목 추가
- 지역 강세/약세 → `data/prefectures.json`의 `lean` (1보다 크면 강세)

GitHub 커넥터로 Claude에게 "참정당 색을 바꿔줘", "오사카 유신 강세를 낮춰줘"처럼 요청해도 됩니다. 규칙은 `CLAUDE.md`에 있습니다.
